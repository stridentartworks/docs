### Example: Release notes pipeline  
  
Release notes are a good fit for structured outputs. The agent reads git history using Bash, categorizes commits by type, 
and returns data your CI pipeline can act on directly. Common workflows include updating a changelog, posting to Slack, or 
gating a deployment on breaking changes.  
  
The schema uses an `enum` constraint on `version_bump` to enforce reliable semantic versioning categories, and separate arrays 
for each change type so downstream code can handle them independently. The example also demonstrates exiting after the `async for` 
loop to avoid async generator cleanup issues when making decisions based on structured output results.
  
<CodeGroup>  
  ```typescript TypeScript theme={null}  
  // TBD - didn't get to it in time but asked the docs assistant to generate it based on the Python example
  ```

  ```python Python theme={null}
  import asyncio  
  import sys  
  from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage  
    
  release_schema = {  
      "type": "object",  
      "properties": {  
          "version_bump": {"type": "string", "enum": ["major", "minor", "patch"]},  
          "summary": {"type": "string"},  
          "breaking_changes": {"type": "array", "items": {"type": "string"}},  
          "new_features": {"type": "array", "items": {"type": "string"}},  
          "bug_fixes": {"type": "array", "items": {"type": "string"}},  
      },  
      "required": ["version_bump", "summary"],  
  }  
    
    
  async def main():  
      has_breaking_changes = False  
        
      async for message in query(  
          prompt="Analyze the last 10 git commits and generate release notes. Categorize each commit as a breaking change, new feature, or bug fix. Recommend a version bump following semantic versioning.",  
          options=ClaudeAgentOptions(  
              output_format={"type": "json_schema", "schema": release_schema}  
          ),  
      ):  
          if isinstance(message, ResultMessage) and message.structured_output:  
              notes = message.structured_output  
                
              print(f"Recommended bump: {notes['version_bump']}")  
              print(f"\n{notes['summary']}")  
                
              if notes.get("breaking_changes"):  
                  print("\nBreaking changes:")  
                  for change in notes["breaking_changes"]:  
                      print(f"  - {change}")  
                  has_breaking_changes = True  
                
              if notes.get("new_features"):  
                  print("\nNew features:")  
                  for feature in notes["new_features"]:  
                      print(f"  - {feature}")  
                
              if notes.get("bug_fixes"):  
                  print("\nBug fixes:")  
                  for fix in notes["bug_fixes"]:  
                      print(f"  - {fix}")  
         
      if has_breaking_changes:  
          sys.exit(1)  
    
    
  asyncio.run(main())
  ```
