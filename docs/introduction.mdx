## What is Pets Galore?

Pets Galore is an inference cloud platform that provides the infrastructure for streaming AI video as it's generated.
Built for products that run video continuously, from interactive scenes to live worlds.

### Interactive, continuous streaming
Create a session, stream output, and control it live.

```typescript
import { createApp, createStore, videoStream } from '@urun/core';
const store = createStore({ endpoint: 'wss://your-app.urun.sh' });
const app = createApp({ store });
// Create the session
const session = await app.call('generate_video', {
  prompt: 'A live lofi room with a character reacting to music',
});
// Wire video stream into a <video> element
const video = session.stream('video');
document.querySelector('video').srcObject = videoStream(video);
// Send controls back
session.emit('control', { action: 'pause' });
```
